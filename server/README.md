# Backend

Node.js + Express + MongoDB API for the Student Registration Portal.

## Run

```bash
npm install
copy .env.example .env
npm run dev
```

On macOS/Linux:

```bash
cp .env.example .env
npm install
npm run dev
```

## Test

```bash
npm test
```

See the root `README.md` and `docs/API.md` for complete instructions.
